# B50 image: replace left sidebar with a top profile header

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The 210px left sidebar on the B50 image is mostly empty space. Replace it with a full-width profile header above NEW CHARTS, styled after the user's reference (avatar, spaced name, stat columns with dividers, rating plate on the right).
Data already stored by the sync (settings table): profile_name, profile_avatar, profile_rating, profile_rating_base (rating plate image), profile_course_rank (Dan image), profile_class_rank (Class image), profile_title (trophy), profile_total_plays / profile_version_plays. Stars aren't stored (the regex finds nothing).

Plan (awaiting approval):
1. Remove drawSidebar. The canvas loses 210px of width and the cards start at PAD.
2. New drawProfileHeader, full card-grid width, about 84px tall, light panel in the same style as the NEW CHARTS pill:
   - Avatar, rounded square (about 68px).
   - Name, large and letter-spaced, with the trophy title in small muted text under it.
   - Stat columns with thin dividers: Plays | Dan (course rank image) | Class (class rank image) | New / Old totals.
   - Rating on the right: the in-game rating plate with the digits drawn over it. If the plate can't be fetched, fall back to a drawn box in the tier colour.
3. Sega-hosted images: fetch with a timeout and a 10-minute miss cache. If one fails, skip that column; the header must never fail.
4. Pass the new fields through app/api/b50-image/route.ts.
5. Move "generated by moimoi · date" to a small line at the bottom right.
6. Leave Stars out (not synced).
7. Verify by rendering /api/b50-image, then run tsc and eslint.
